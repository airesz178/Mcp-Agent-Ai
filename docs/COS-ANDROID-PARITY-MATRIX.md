- **Implemented+verified** — COS behavior has been reproduced end to end in the target Android app and verified with Android runtime evidence. No row presently meets this bar.
- **Android equivalent+verified** — a narrower Android-native equivalent exists and its indicated **shared Rust unit tests passed on Windows**; **not** a verified equivalent of all COS semantics and **not** proof of execution on a physical Android device. - **Pending** — absent, only UI, only Node/legacy Java, or source implementation exists but the necessary target behavior/test evidence is absent. A compiled Android APK alone does not change the status.
- **Blocked** — a specific external, architectural, device-acceptance, or dependency gate prevents the claimed COS behavior today. The table identifies the gate; this does not mean Android can never support it.
